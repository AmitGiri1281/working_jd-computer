# ⚙ Installation

Clone the repository

```bash
git clone https://github.com/yourusername/healvance-ai.git
```

Move into project

```bash
cd healvance-ai
```

Install dependencies

```bash
npm install
```

Start development server

```bash
npm run dev
```

---

# 🏗 Build for Production

```bash
npm run build
```

Preview production build

```bash
npm run preview
```
